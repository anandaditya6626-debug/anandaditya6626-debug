# Aditya Anand — GitHub Profile Kit

## Install
1. Open https://github.com/new
2. Create a **public** repository named exactly `anandaditya6626-debug`.
   If that profile repository already exists, open it instead.
3. Upload the contents of this folder (including `.github` and `assets`) to the repository root.
4. Ensure `README.md` is at the root, then commit.
5. Visit https://github.com/anandaditya6626-debug to view the profile.

## Before publishing
- Verify every project URL in `README.md`; replace any demo URL that has changed.
- The Code Mentor repository link is `https://github.com/anandaditya6626-debug/CODEMENTOR`.
- The custom section headings, banner, and footer are local SVGs, so they don't depend on an external image host.
- GitHub stats, streak, and activity cards are served by third-party services and may occasionally be unavailable. They display data from public GitHub activity; no statistics are hard-coded.
- The banner is a designed graphic, not an ASCII portrait. If you want a personal ASCII portrait, provide a photo and it can be created separately.

## Personalize
Edit `README.md` to update your bio, project descriptions, and links. The skill list intentionally avoids claiming expertise in tools you are still learning.
