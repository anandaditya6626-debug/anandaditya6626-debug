# Aditya Anand — GitHub Profile Kit (Easy Upload)

## Upload instructions
1. Open your profile repository: https://github.com/anandaditya6626-debug/anandaditya6626-debug
2. Click **Add file → Upload files**.
3. From this folder, select `README.md` and all seven `.svg` files together.
4. Drag them into GitHub's upload area.
5. Scroll down and click **Commit changes**.
6. Refresh your profile.

All files in this package are meant to be uploaded directly to the repository root. No `assets` folder is needed.

If GitHub shows that `README.md` already exists, uploading this one will update/replace its contents when you commit. Keep the SVG files at the root beside README.md.
